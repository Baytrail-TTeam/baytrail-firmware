# acpi

Artefakty tej kategorii dodaj przez `scripts/catalog.py add --kind acpi`. Oryginały trafiają do firmware/<platform>/acpi; oryginały konkretnych urządzeń mogą być grupowane w firmware/devices/<vendor>/<model>/acpi. Pochodne trafiają do experiments. Metadane: docs/METADATA.md.

Nie ma automatycznej instalacji ani zapisu na urządzenie.
