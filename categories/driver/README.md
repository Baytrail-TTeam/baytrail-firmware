# driver

Artefakty tej kategorii dodaj przez `scripts/catalog.py add --kind driver`. Oryginały trafiają do firmware/<platform>/driver; oryginały konkretnych urządzeń mogą być grupowane w firmware/devices/<vendor>/<model>/driver. Pochodne trafiają do experiments. Metadane: docs/METADATA.md.

Nie ma automatycznej instalacji ani zapisu na urządzenie.
