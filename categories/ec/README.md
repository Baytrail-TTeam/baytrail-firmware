# ec

Artefakty tej kategorii dodaj przez `scripts/catalog.py add --kind ec`. Oryginały trafiają do firmware/<platform>/ec; oryginały konkretnych urządzeń mogą być grupowane w firmware/devices/<vendor>/<model>/ec. Pochodne trafiają do experiments. Metadane: docs/METADATA.md.

Nie ma automatycznej instalacji ani zapisu na urządzenie.
