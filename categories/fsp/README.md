# fsp

Artefakty tej kategorii dodaj przez `scripts/catalog.py add --kind fsp`. Oryginały trafiają do firmware/<platform>/fsp; oryginały konkretnych urządzeń mogą być grupowane w firmware/devices/<vendor>/<model>/fsp. Pochodne trafiają do experiments. Metadane: docs/METADATA.md.

Nie ma automatycznej instalacji ani zapisu na urządzenie.
