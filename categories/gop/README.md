# gop

Artefakty tej kategorii dodaj przez `scripts/catalog.py add --kind gop`. Oryginały trafiają do firmware/<platform>/gop; oryginały konkretnych urządzeń mogą być grupowane w firmware/devices/<vendor>/<model>/gop. Pochodne trafiają do experiments. Metadane: docs/METADATA.md.

Nie ma automatycznej instalacji ani zapisu na urządzenie.
