# optionrom

Artefakty tej kategorii dodaj przez `scripts/catalog.py add --kind optionrom`. Oryginały trafiają do firmware/<platform>/optionrom; oryginały konkretnych urządzeń mogą być grupowane w firmware/devices/<vendor>/<model>/optionrom. Pochodne trafiają do experiments. Metadane: docs/METADATA.md.

Nie ma automatycznej instalacji ani zapisu na urządzenie.
