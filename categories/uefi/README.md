# uefi

Artefakty tej kategorii dodaj przez `scripts/catalog.py add --kind uefi`. Oryginały trafiają do firmware/<platform>/uefi; oryginały konkretnych urządzeń mogą być grupowane w firmware/devices/<vendor>/<model>/uefi. Pochodne trafiają do experiments. Metadane: docs/METADATA.md.

Nie ma automatycznej instalacji ani zapisu na urządzenie.
