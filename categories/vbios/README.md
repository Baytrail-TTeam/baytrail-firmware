# vbios

Artefakty tej kategorii dodaj przez `scripts/catalog.py add --kind vbios`. Oryginały trafiają do firmware/<platform>/vbios; oryginały konkretnych urządzeń mogą być grupowane w firmware/devices/<vendor>/<model>/vbios. Pochodne trafiają do experiments. Metadane: docs/METADATA.md.

Nie ma automatycznej instalacji ani zapisu na urządzenie.
