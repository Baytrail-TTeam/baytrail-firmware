# vbt

Artefakty tej kategorii dodaj przez `scripts/catalog.py add --kind vbt`. Oryginały trafiają do firmware/<platform>/vbt; oryginały konkretnych urządzeń mogą być grupowane w firmware/devices/<vendor>/<model>/vbt. Pochodne trafiają do experiments. Metadane: docs/METADATA.md.

Nie ma automatycznej instalacji ani zapisu na urządzenie.
